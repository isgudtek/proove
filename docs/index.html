Proove

An open agentic marketplace for unique artifacts: meteorite fragments, rare minerals, precious metals, antique coins, limited-edition art and historic documents. A vendor cannot just say it has an item. Each offer carries a zero-knowledge proof (Noir circuit, UltraHonk) that the vendor knows the secret code of an item certified by the registry, bound to that one listing. The buyer's hub verifies every proof in the browser with the registry's own verification key and checks custody at the registry before anything is bought.
